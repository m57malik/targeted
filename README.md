# TARGETED

An interactive first-person reconnaissance map of the automated systems in Moosa's daily life, created for GBDA 413.

## Play

Open `index.html` in a desktop browser, or visit the GitHub Pages deployment for this repository.

- Move the pointer to aim.
- Press Space or Z, right-click, or select Scope to zoom.
- Click an app marker to fire and reveal its role.
- Alternatively, select one of the eleven signal buttons along the bottom.
- Explore all eleven systems to reach the final reveal.
- Sound is optional. Reduced-motion preferences are respected.

## Publish on GitHub Pages

This is a static site; there is no build step or backend.

In repository Settings → Pages, select Deploy from a branch, choose the main branch and the root folder, then save. Use the live URL GitHub provides after deployment finishes.

## Files

- `index.html`, `style.css`, `game.js`: playable experience
- `targeted-poster.png`: 1600 × 1200 submission poster
- `targeted-poster.svg`: editable poster
- `statement.txt`: 137-word artist statement

## Context

The map reconstructs personal reflections rather than a measured two-week field log. Usage ranges and rankings are illustrative, not recorded screen-time data. Terrain and app symbols are stylized. AI assisted the concept, code, and graphics.

The first-person shooter visual language is inspired by games the author grew up playing. No Call of Duty game assets are included, and the project is not affiliated with Call of Duty.
